# 0011. コンテキストメニューのリンク ID を安定化し空フォルダを出さない

Date: 2026-09-06
Status: Accepted

## Context

ツールバー右クリックで矢印のない「My Bookmark」を選ぶと、別 URL のエラーページが開く。メニュー項目 ID が毎回 `m1` 形式で振り直され、フォルダクリック時に「URL なし → 再構築 → 同じ ID が別リンク」になって誤ってタブを開いていた。空の H1 も葉項目のように見える。

## Decision

- ブックマーク用メニュー ID は URL から作る安定 ID にする。フォルダはパス由来の ID。
- `onClicked` で targets に無い ID（フォルダや不明項目）はタブを開かない。セッション喪失時だけメニュー再構築し、その場では開かない。
- 子が無いフォルダはメニューに出さない。
- ページ用ルートのタイトルは拡張名と区別するため `Bookmarks` にする。

## Consequences

- 空の `# My Bookmark` などが見えなくなる。
- フォルダを選んでもタブが開かない。
- ツールバーメニューの先頭付近にあった紛らわしい葉の「My Bookmark」が消える想定。
