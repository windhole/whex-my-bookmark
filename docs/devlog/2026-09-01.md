## 21:00 〜 Chrome先行の個人用ブックマーク拡張 v1

### やったこと
- ADR-0001〜0003 を実装前に起票（MV3+Vite、storage.local、Markdown方言と先頭8 H1）
- Chrome MV3 拡張のスキャフォルド、`make chrome`、firefox/safari は stub
- 制限付き Markdown の parse / serialize / 指定エリア末尾へ追記
- ツールバーの色付き8スロット保存、contextMenus、`Alt+1`〜`4` のコマンド
- オプションで Markdown 編集とファイル import/export
- 単体テスト 13件と `dist/chrome` の本番ビルドまで通した
- Chrome への読み込み確認は権限が必要なため、利用者側で行う

### 詰まった点・気づき
- Chrome が自動で割り当てる suggested_key は4つまでなので、5〜8は shortcuts 画面で付ける
- ポップアップ HTML の `crossorigin` は拡張ページでは邪魔になり得るので、ビルド後に外している
