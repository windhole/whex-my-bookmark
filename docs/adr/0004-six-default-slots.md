# 0004. ワンタッチ保存は6スロット、メニューでは Default Slot 配下

Date: 2026-09-01
Status: Superseded by ADR-0006

## Context

保存先は「見てすぐ選ぶ」枠なので、8個だとボタンがやや多い。一方、Markdown の H1 は保存枠以外の分類にも使いたい。閲覧メニューで保存枠とそれ以外の見出しが同じ並びに並ぶと、ワンタッチ先がどこか分かりにくい。ADR-0003 の「先頭8 H1 = 保存スロット」を改める。

## Decision

- ワンタッチ保存スロットは文書先頭から6個の H1。色と `Alt+1`〜`Alt+6`、ポップアップの `1`–`6` はスロット番号。
- H1 が6未満なら空エリアを末尾に足す。7個目以降の H1 はメニューに出すが保存先にしない。
- 閲覧用の階層メニューでは、6つの保存エリアを `Default Slot` フォルダの子にする。7個目以降の H1 は `Default Slot` の兄弟として並べる。
- Markdown 方言（ATX、`- [title](url)`、インデント annotation）は ADR-0003 のまま。

## Consequences

- ポップアップは6色になり、保存ショートカットも6本まで。
- 既存の8 H1 文書は、先頭6つがワンタッチ先、残り2つはメニュー専用の通常フォルダになる（自動では消さない）。
- メニューが1段深くなるので、Chrome の contextMenus 深さ制限には以前より早く当たる。
