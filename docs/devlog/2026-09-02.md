## 07:16 〜 service worker が Cannot access before initialization で落ちる

### やったこと
- `void queueBootstrap()` が `let work` より前に走っていた TDZ を直し、キュー変数を先に初期化する

### 詰まった点・気づき
- Chrome は manifest 全体をエラー詳細に出す。実体は `Cannot access 'f' before initialization`（service worker registration failed, status 15）
- 以前は async の `bootstrap()` が最初の await で一旦戻るので、後段の `let` 初期化に間に合っていた
